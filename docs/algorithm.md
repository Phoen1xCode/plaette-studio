# 色阶生成算法

[`src/lib/palette.ts`](../src/lib/palette.ts) 将主色转换为十级 sRGB 色阶。Culori 负责颜色解析和空间转换；彩度路径、色域搜索与采样策略由本项目实现。算法优先保证完整明度范围和自然过渡，不强制把输入主色放在某一级。

## 输入归一化

`normalizeColor` 接受长度不超过 160 的不透明颜色字符串，解析后检查数值有效性。广色域输入将明度限制在 `[0, 1]`，保持色相、缩减彩度至 sRGB 范围，再量化为 HEX，作为后续计算的种子。透明色需要指定合成背景，因此拒绝 alpha 不等于 1 的输入。

## 彩度路径与色域映射

算法在 OKLCH 中分别控制感知明度 `L`、彩度 `C` 和色相 `h`，固定种子色相，沿明度方向生成路径。设种子为 `(Ls, Cs, hs)`，品牌色的彩度包络为：

```text
Es = max(0.35, sin(π × Ls)) ^ 0.8
P = min(0.4, Cs / Es)
Cdesired(L) = P × sin(π × L) ^ 0.8
```

`Es` 的下限限制近黑、近白种子的彩度放大，避免将轻微染色放大成高饱和色。不同模式的参数如下：

| 模式       | 明度范围     | 峰值彩度参数            |
| ---------- | ------------ | ----------------------- |
| 浅色品牌色 | 0.975 → 0.20 | `P`                     |
| 深色品牌色 | 0.90 → 0.16  | `P × 0.82`              |
| 关联中性色 | 跟随对应模式 | `min(0.022, Cs × 0.12)` |
| 无彩输入   | 跟随对应模式 | `Cs < 0.0001` 时置零    |

对每个 `(L, h)`，在彩度 `[0, 0.4]` 内二分搜索 22 次，求 sRGB 可用的最大彩度 `Cmax`，最终取 `C = min(Cdesired, Cmax)`。转换到 HEX 前仅清理浮点舍入造成的微小通道越界，避免直接裁切 RGB 通道引入额外色相偏移。

## 等弧长采样

先沿明度计算 193 个路径点，再累计相邻点在 OKLab 中的距离。由于色相固定，距离可简化为：

```text
distance = sqrt((ΔL)² + (ΔC)²)
```

将累计路径长度均分为九段，定位十个采样位置，再根据路径函数求色并量化为 8 位 HEX。相比直接等分明度，这样能将色域边界上的彩度变化计入步距。

等弧长不等于相邻输出颜色的直线距离完全相等，路径曲率和 HEX 量化都会引入误差。测试在实际输出 HEX 上检查明度严格递减，并对代表色与 RGB 网格样本要求最大 / 最小相邻步距比小于 1.4。

## 组件主题与对比度

[`src/lib/theme.ts`](../src/lib/theme.ts) 将色阶映射为品牌色、背景、文字和边框。深色数组仍由浅到深，组件角色根据背景选取，不反转数组。

品牌色从同时满足容器与染色背景上 WCAG 2.x 对比度 4.5:1 的候选中，选择最接近第 6 级的颜色；没有候选时回退到对应模式的端点。按钮文字取黑白中对比度更高的一方；Hover / Active 邻级只有同时满足容器与按钮文字的对比度要求才启用，否则沿用品牌色。

对比度采用 sRGB 相对亮度公式 `(Ymax + 0.05) / (Ymin + 0.05)`，独立于 OKLab 色差。色阶排序和平滑性不能替代具体文字与背景组合的可读性检查。

## 边界与取舍

评估极端颜色时需要考虑以下行为：

- 黑、白、灰均生成完整无彩灰阶；无彩种子无法推断品牌色相。
- 固定黄色相的深端呈橄榄色；极浅粉的深端保持低彩度，不强行提升饱和度。
- 输入主色保存在 `source`，需要精确品牌色的场景应单独使用该值，不假设第 6 级等于输入。
- 输出限定为 sRGB 8 位颜色。等弧长是感知近似，不保证所有背景、显示器或观察者都获得相同观感，也不保证任意色块组合满足无障碍要求。
